# Demo meeting recording

`annapurna-handover-call.wav` is a 72-second synthetic handover call for Project Annapurna (two computer voices:
Priya explains, Arjun asks). `annapurna-handover-call.vtt` is the same call as a Teams-style transcript with speaker
names and exact timestamps.

- Upload the **.wav** as a *Meeting recording* to see transcription, suggested speaker names and click-to-play.
  This needs an AI provider with Whisper (Groq or OpenAI) in Organisation settings → AI.
- Upload the **.vtt** to try recordings without any AI. Claims still cite the second each thing was said; there is
  no audio to play.

What the call adds to the handover: the Razorpay webhook secret must be rotated every 90 days (next on 5 December),
only Priya can do it, Mr Joshi approves menu changes on Thursdays only, the menu cache still breaks every Monday,
and dark mode moved out of the launch scope to January.
